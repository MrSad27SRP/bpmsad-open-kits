# BPMSad Open Kits

بستهٔ رایگان ثبت و پیگیری درخواست خدمات عمومی. همهٔ نمونه‌ها با دادهٔ ساختگی کار می‌کنند.

| بسته | شروع |
| --- | --- |
| کامپوننت فرم فارسی | [index.html](index.html) را در مرورگر باز کنید و یک درخواست نمونه دانلود کنید. |
| مدل فرایند | [request.bpmn](request.bpmn) را در ابزار مدل‌سازی BPMN وارد کنید. |
| مدل داده | [schema.sql](schema.sql) را روی پایگاه SQLite خالی اجرا کنید. وضعیت اولیه pending است. |
| کانکتور نمونه | [connector.mjs](connector.mjs) درخواست فرم را به یک API سازگار ارسال می‌کند. |

کانکتور با Node اجرا می‌شود. مقصد باید یک URL کامل و مورد اعتماد باشد. API مقصد باید POST با بدنهٔ JSON شامل title و description بپذیرد و در پاسخ موفق یک JSON برگرداند. نمونهٔ محلی در آزمون قابل مشاهده است.

```js
import { submitRequest } from './connector.mjs';
await submitRequest('http://localhost:3000/requests', {
  title: 'درخواست نمونه',
  description: 'شرح آزمایشی'
});
```

آزمون کانکتور با دستور node --test اجرا می‌شود. مدل فرایند برای مستندسازی طراحی شده است. کامپوننت و کانکتور نمونهٔ وب و Node هستند و بستهٔ نصب Bizagi ندارند.

## مشارکت

برای پیشنهاد فرایند بعدی یک Issue باز کنید و نقش‌ها، ورودی‌ها و خروجی فرایند را بنویسید. برای تغییر کد، همراه PR مراحل اجرای نمونه و نتیجهٔ آزمون را درج کنید.

## منابع طراحی

- [bpmn-js](https://github.com/bpmn-io/bpmn-js) الگوی نمایش مدل BPMN در وب برای مرحلهٔ بعد.
- [bpmn-js-examples](https://github.com/bpmn-io/bpmn-js-examples) الگوی نمونه‌های کوچک و مستقل با راهنمای اجرا.
- [bpmn-moddle](https://github.com/bpmn-io/bpmn-moddle) مرجع ابزارخوانی XML مدل BPMN.

پیاده‌سازی این بسته مستقل است و فایل‌های پروژه‌های مرجع را در بر ندارد.

## مسیر توسعه

۱. دریافت بازخورد دربارهٔ فرم و مدل درخواست خدمات.
۲. افزودن نمایش تعاملی BPMN و یک مدل داوطلبی با دادهٔ نمونه.
۳. بسته‌بندی جداگانه برای Bizagi پس از اعتبارسنجی در Studio و Work Portal.
